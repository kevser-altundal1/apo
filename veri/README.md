# veri/

Ham veri buraya konur. Bu klasördeki dosyalar **değiştirilmez, tahmin edilmez, "düzeltilmez"** (bkz. kök dizindeki `CLAUDE.md` → Veri bütünlüğü ve doğrulama).

Analiz sırasında türetilen (temizlenmiş, dönüştürülmüş) veriler buraya değil, `analiz/` altına ayrı bir alt klasöre (örn. `analiz/islenmis-veri/`) konur — ham veriyle karışmasın.
